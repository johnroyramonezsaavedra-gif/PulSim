# PulSim

Browser-based circuit builder and simulator.

- Wires can start or end on any wire (Shift+click a wire, or right-click it and choose "Start wire here").
- PLC simulator window (toolbar button): Structured Text programs, I/O panel, board PLC part.
- Spectrum analyzer (FFT) part and window.
- Logic LED part (glows and shows 1 / 0).

Live site: enable GitHub Pages (Settings > Pages > Deploy from a branch > main / root).
